Knapton Twin product page

Open index.html in a browser, or upload the whole folder to a web server.

Contents
- index.html: the page
- support.js: page runtime (keep it next to index.html)
- assets/: logo, Next Level logo, action photo

The Graphics slider, spec icons, related boards and video thumbnails load from donek.com and YouTube, and the fonts load from Google Fonts. An internet connection is needed for those.
