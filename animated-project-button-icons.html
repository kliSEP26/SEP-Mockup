Button icon explorations

Three ways to show work has started

Hover over a button to see “Start Collaboration...” and animate the icon beside the text. Move the cursor away to reset it. Keyboard focus shows the same effect. Every icon inherits one colour and uses CSS motion. No image downloads or animation package.

Integration: Copy the preferred button markup and its CSS rules. The label switches to “Start Collaboration...” and the icon animates in place on :hover and :focus-visible, with no JavaScript required.
Accessibility: The buttons retain accessible labels; decorative SVGs are hidden from screen readers. Reduced-motion settings stop the looping animation.
